# Landscape Tycoon - 景观大亨

一款像素风格的景观美化公司经营游戏，结合了星露谷物语的田园风格和任务管理玩法。

## 🎮 游戏简介

你扮演一名景观美化公司的老板，在城市中接取各种任务（修剪草坪、种植花卉、铺设砖面等），通过完成工作赚取资金，升级属性和工具，最终扩张公司规模。

## 📋 当前版本：MVP 快速原型

### ✅ 已实现功能
- 城市大地图探索（俯视角）
- 玩家角色移动（8方向）
- 建筑物交互系统
- 任务系统（接取和完成）
- 工作机制（基于属性的自动工作）
- 属性系统（力量、敏捷、灵巧、声望）
- 经济系统（金币、经验、升级）
- 完整UI系统（HUD、任务面板、工作界面、评分面板）
- 任务评分系统（1-5星）
- 升级系统（每级获得3点可分配属性点）

### 🎯 核心玩法循环
```
探索城市 → 接取任务 → 完成工作 → 获得评分 → 
赚取金币 → 提升属性 → 接取更难的任务
```

## 🎲 游戏系统

### 属性系统
- **力量**: 影响手动工作速度（挖坑、铲土、除草）
- **敏捷**: 影响移动速度、电动工具使用、清理垃圾
- **灵巧**: 影响小游戏容错率（未来实装）
- **声望**: 解锁高级任务和稀有材料

### 任务类型（当前版本）
1. 清理垃圾 - 入门任务
2. 修剪草坪 - 基础任务
3. 种植花卉 - 需要声望100
4. 铺设砖面 - 需要声望100
5. 建造围栏 - 需要声望300

### 评分系统
任务完成后根据时间和质量评分（1-5星）：
- 5星: 150%报酬 + 25声望
- 4星: 120%报酬 + 20声望
- 3星: 100%报酬 + 15声望
- 2星: 80%报酬 + 10声望
- 1星: 50%报酬 + 5声望

## 🎨 技术栈

- **引擎**: Godot 4.3+
- **语言**: GDScript
- **美术风格**: 像素艺术（16x16 / 32x32）
- **分辨率**: 1280x720

## 🚀 快速开始

### 前置要求
- Godot Engine 4.3 或更高版本

### 安装步骤

1. **克隆或下载项目**
   ```
   下载整个 LandscapeTycoon 文件夹
   ```

2. **在 Godot 中打开项目**
   - 启动 Godot
   - 点击"导入"
   - 选择 `LandscapeTycoon/project.godot`
   - 点击"导入并编辑"

3. **创建场景文件**
   
   ⚠️ **重要**: 由于场景文件(.tscn)无法通过文本生成，你需要手动创建它们。
   
   **请参考 `SCENE_SETUP_GUIDE.md` 文档**，按照详细步骤创建所有场景。
   
   建议顺序：
   1. Player 场景
   2. Building 场景
   3. HUD 和 UI 场景
   4. CityMap 场景
   5. WorkSite 相关场景

4. **运行游戏**
   - 按 F5 或点击"运行项目"
   - 第一次运行会要求选择主场景
   - 选择 `scenes/city/CityMap.tscn`

## 🎮 控制说明

|------|------|
| 移动 | WASD 或 方向键 |
| 交互 | E 或 空格 |
| 菜单 | ESC |

## 📖 游戏流程

### 第一次游玩

1. **开始游戏**
   - 你会出现在城市地图上
   - 查看左上角的HUD了解当前状态

2. **前往任务中心**（黄色建筑）
   - 走近建筑，按 E 进入
   - 浏览可接取的任务
   - 选择一个简单任务（如"清理垃圾"）

3. **前往客户家**（红色建筑）
   - 地图上会标记任务位置
   - 走到客户家门口，按 E 开始工作

4. **完成工作**
   - 在工作场景中，走到绿色工作区域
   - 按 E 开始工作
   - 等待进度条完成
   - 完成所有工作区域

5. **查看评分**
   - 任务完成后会显示评分结果
   - 获得金币、经验和声望
   - 点击"返回城市"

6. **升级属性**
   - 获得足够经验后会升级
   - 获得可分配属性点
   - 前往公司（蓝色建筑）分配属性（未来版本实装）

7. **继续接取任务**
   - 随着声望提升，解锁更多任务类型
   - 购买更好的工具提高效率（未来版本实装）
